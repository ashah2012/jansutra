# Tools & Usage

Three Python CLI tools in `tools/` cover the full development and analysis workflow.

## Installation

```bash
# Runtime dependencies only
pip install rdflib pyshacl rich

# Or as a package (enables console script aliases)
pip install -e .

# With documentation build dependencies
pip install -e ".[docs]"
```

---

## validate.py

Validates a Jansutra data file against all SHACL shapes. Exits with code 0 on success, 1 on violations.

```
python tools/validate.py <data-file.jsonld> [data-file2.jsonld ...]
```

**What it does:**

1. Parses each data file argument into an rdflib `Graph`
2. Loads all `ontology/*.jsonld` files into a second graph
3. **Merges** the two graphs: `merged = data_graph + ontology_graph`
   — this is essential so that `skos:inScheme` triples (defined in the ontology) are present as facts when pyshacl evaluates `sh:hasValue` scheme membership checks
4. Loads all `shapes/*.shacl.ttl` files into the shapes graph
5. Calls `pyshacl.validate(merged_graph, shacl_graph=shapes_graph, inference="rdfs", abort_on_first=False)`
6. Prints a Rich-coloured report

**Example:**

```bash
python tools/validate.py examples/household-001.jsonld
```

```
Loaded data: examples/household-001.jsonld
Loaded 7 ontology module(s)
Loaded 7 SHACL shape file(s)
✓ Data conforms to all SHACL shapes.
```

**Console script alias (after `pip install -e .`):**

```bash
jansutra-validate examples/household-001.jsonld
```

## query.py

Runs a SPARQL query against the ontology and optional data files. Prints SELECT results as a Rich table, ASK results as a boolean.

```
python tools/query.py <query.sparql> [data-file.jsonld ...]
```

**What it does:**

1. Loads all `ontology/*.jsonld` files into an rdflib `ConjunctiveGraph`
2. Parses any additional data file arguments into the same graph
3. Reads the SPARQL query file
4. Executes `graph.query(query_text)`
5. For SELECT: renders results as a Rich table with variable names as column headers
6. For ASK: prints the boolean answer

**Example:**

```bash
python tools/query.py sparql/vulnerability-query.sparql examples/household-001.jsonld
```

```

├──────────────────────────────────────────────┼───────────────┼──────────────┼──────────────┤

└──────────────────────────────────────────────┴───────────────┴──────────────┴──────────────┘
1 result(s)
```

**Console script alias:**

```bash
jansutra-query sparql/vulnerability-query.sparql examples/household-001.jsonld
```

## convert.py

Converts JSON-LD ontology files to Turtle (`.ttl`). The derived Turtle files in the repository were generated by this tool.

```
# Convert all ontology/*.jsonld files
python tools/convert.py

# Convert a single file
python tools/convert.py ontology/social.jsonld
```

**What it does:**

1. For each source file: `g.parse(src, format="json-ld")`
2. Serialises: `g.serialize(destination=dest, format="turtle")`
3. Output path is the same directory as the source with `.ttl` extension

**Example:**

```bash
python tools/convert.py
```

```
✓ core.jsonld → ontology/core.ttl
✓ economic.jsonld → ontology/economic.ttl
✓ geography.jsonld → ontology/geography.ttl
✓ health.jsonld → ontology/health.ttl
✓ land.jsonld → ontology/land.ttl
✓ services.jsonld → ontology/services.ttl
✓ social.jsonld → ontology/social.ttl

Converted 7 file(s).
```

**Console script alias:**

```bash
jansutra-convert
jansutra-convert ontology/social.jsonld
```

## Console script names

All three aliases are defined in `pyproject.toml`:

```toml
[project.scripts]
jansutra-validate = "tools.validate:main"
jansutra-query    = "tools.query:main"
jansutra-convert  = "tools.convert:main"
```

They become available in `PATH` after `pip install -e .`.
